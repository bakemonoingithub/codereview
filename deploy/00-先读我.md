# 离线部署包入口

- 首次安装或从九月旧系统切换：阅读[系统部署手册](系统部署手册.md)。
- 启动、停止、重启、配置生效、保留数据升级及失败恢复：阅读[系统运维手册](系统运维手册.md)。
- 已有当前新路线部署的自动升级：使用新包中的 `scripts/update.sh --new <新包目录> --install <原部署目录> --tag <版本>`，参数与适用条件见运维手册第 4.2 节。
- 内网 LLM 试运行参数位于 `config/application.yml.example`。正式运行文件为 `config/application.yml`；已有文件不会被模板自动覆盖。

升级沿用原部署目录、数据目录和配置。数据库结构发生变化时，不能假定换回旧镜像即可恢复。执行前按手册备份并确认版本兼容范围。
