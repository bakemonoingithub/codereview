# 设计基线 - 专项审查与 Agent 分析

状态：P30.7 起使用；P31.6 补充发起审查与范围选择流程。界面依据负责人已批准的 [P29 原型](work/agent-redesign/p29/prototype/index.html) 与 [评审记录](work/agent-redesign/p29/acceptance.md)；本文只把既有界面语言固化为可执行约束，不新增业务范围。

## 1. 设计简报

- **用户**：开发负责人和代码审查执行者，在 PC 浏览器中维护项目、模型、提示词与策略，随后发起专项审查并阅读结果。
- **调性**：克制、专业、高密度。信息优先于装饰；同屏可比较，状态和风险用文字与少量色彩表达。
- **参考**：
  - 已批准的 P29 HTML 原型：页面标题、筛选、表格、表单弹窗与提示条的结构。
  - 现有 Ant Design Vue 列表页：`ListPageLayout` 的标题与操作区、空态与错误态组件。
  - Ant Design 表单惯例：标签在上、字段说明在下、危险操作二次确认。

## 3. 用户流程

### 3.1 项目管理

- 正常：搜索或直接浏览列表 → 新建时填名称、仓库地址、可选令牌与分支 → 保存后回到列表；编辑时仓库地址锁定，令牌留空保留。
- 空状态：说明"还没有项目"并给出新建入口。
- 加载：表格 loading；翻页保留已加载项。
- 错误：列表加载失败显示可重试提示；保存失败保留表单并显示服务端原因。

### 3.2 模型管理

- 正常：列表显示模型名、地址、凭据状态、窗口／最大输出与验证状态 → 新建或编辑容量档案 → 验证只检查可达与简单 JSON。
- 空状态：提示先接入模型，才能在策略中选用。
- 加载：验证按钮在请求期间禁用，防止重复外呼。
- 错误：验证失败展示原因而不是"验证完成"；配置修订后旧验证显示为已过期。

### 3.3 提示词管理

- 正常：列表查看名称、用途、标签与修订 → 编辑元数据与正文 → 正文变化时新增版本 → 版本弹窗选择两版对比。
- 空状态：提示提示词是可复用审查规则，并给出新建入口。
- 加载：正文慢响应不覆盖用户已输入内容；版本列表加载失败不残留上一次的版本选项。
- 错误：对比失败显示错误并清空上一对版本的结果，不伪装成"内容相同"。

### 3.4 策略管理

- 正常：列表显示专项类型、关联模型与提示词 → 新建时先选专项类型，再选模型和可选提示词 → 保存后用于发起任务。
- 空状态：说明策略由专项类型、模型和提示词组成。
- 加载：模型／提示词下拉加载失败时说明原因，并提供跳转到对应管理页的入口。
- 错误：未选模型不提交；被其他配置引用时删除失败并展示原因。

### 3.5 发起审查与范围选择

- 正常：审查中心 → 发起审查 → 选项目、专项类型、文件内容或提交差异 → 读取分支固定版本或选择提交 → 在独立弹窗勾选文件；点击蓝色文件名只预览，复选框只调整目标 → 确认回填，逐个文件可填可选说明 → 选策略（或模型）与默认关闭的智能拆分 → 提交后在审查中心看到新任务。
- 空状态：没有项目时说明需先在项目管理创建；没有目标文件时提交按钮不可用；范围弹窗没有匹配文件时显示"没有匹配的文件"。
- 加载：分支版本读取中显示读取态；文件列表 loading；预览 loading。
- 错误：分支版本、文件列表或提交详情读取失败保留已输入内容并给出重试；提交返回 `SOURCE_MOVED` 时明确提示版本已移动，刷新后清空不适用范围；复制参数时分支已移动则清空原范围。
- 复制：审查中心列表的"复制参数"打开新表单，重新读取当前版本与配置；原任务输入与结果不变。

### 3.6 审查中心

- 正常：按项目、专项类型、状态筛选任务，显示文件完成数和状态；可进入详情或复制参数。
- 空状态：没有任务时说明并给出"发起第一个审查"。
- 加载：表格 loading，刷新不清空已显示行。
- 错误：列表失败显示可重试提示，不把失败写成空列表。

### 3.7 代码浏览

- 正常：选项目、分支 → 文件内容或提交差异 → 树内搜索与勾选，点击文件名预览原文/差异 → 勾选文件带入发起审查。
- 空状态：无项目时提示先在项目管理创建；无文件时显示"没有可浏览的文件"。
- 加载：分支、提交、路径和预览分别显示 loading；切换来源后不保留上一次预览。
- 错误：分支/提交/文件读取失败显示可重试错误；迟到响应不能覆盖新选择或新项目。
- 返回：代码浏览保存固定版本、分支/提交、筛选、树展开、勾选及预览；审查中心从详情返回后，按当前条件重读已加载页数并恢复主要浏览位置。

### 3.8 任务详情与阅读

- 正常：从审查中心进入任务 → 左侧目标文件状态 → 右侧结果/材料/调用页签 → 结果中的位置打开材料弹窗，材料可切换保存片段、固定版本全文与提交差异 → 调用页签打开完整请求/返回。
- 空状态：任务尚无结果时说明"还没有已发布结果"；无材料/调用时分别说明。
- 加载：任务头、结果、材料、调用独立 loading；切换目标使用 epoch，旧响应不覆盖当前目标。
- 错误：任务/结果/材料/调用读取失败分别提示并可重试；同目标刷新失败保留最近成功内容；材料不属于当前任务时明确拒绝。
- 阅读：保存片段始终显示保存正文及原始行号，扩展全文使用材料固定 SHA；切换回来恢复实际发送内容。调用可查看请求、返回、用量及执行代次/单元；耦合结果展示程序事实与材料缺口。
- 部分完成：显示"文件未完成"，只展示已成功片段，不标为完整文件结论，也不进入正式选材。
- 反馈：本阶段只显示"P32 接入"，不提供可提交控件。

## 4. 组件约定

- 页面骨架统一用 `ListPageLayout`；错误态统一用 `LoadErrorAlert`；空态统一用 `EmptyGuide`。
- 发起审查表单用页面分区而非单弹窗；范围选择用独立 `ScopePickerModal`，文件树勾选与文件名预览分离。
- 代码浏览与范围选择共用 `utils/pathTree` 与文件/差异阅读组件；详情结果用 `SpecialistResultView`，材料与调用分别用独立阅读弹窗。
- 列表用 `a-table`，危险操作二次确认；表单用 `a-modal` + `a-form`，标签在上。
- 状态用 `a-tag` + 文字，不只用颜色表达；估算值、验证范围与"未执行"必须写明，不能把工程检查写成真实使用通过。
- 凭据只写不读：界面只显示"已配置／未配置"，编辑时留空表示保留。
