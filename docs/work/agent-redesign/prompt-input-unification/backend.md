# 后端改动方案

业务依据：[契约第 9 节](../business-contract.md#9-提示词输入统一与策略退出2026-10-25)。任务及验收：[工作包](README.md)。本文为待实施方案，字段建议在 UPI-02 定稿。

## 1. 专项发起与校验

字段以 UPI-02 [接口字段稿](interface.md)为评审基线：`TaskDtos.Create` 去掉策略作为配置来源，`modelConfigId` 必填，增加可选 `promptId`、`promptVersionId`。两者应成对：未选规则时均为空；选中规则时版本必填。校验模型可用性、SPECIALIST 用途、版本归属和非空正文，复用 `PromptVersionResolver` 的验证能力，但新入口不借助空版本回退到当前版本。

`TaskService.resolveConfig` 直接解析模型与提示词，删除策略类型校验、模型绑定和策略存在性依赖。新请求携带旧 `strategyId` 时应明确拒绝，不能因 JSON 忽略未知字段而静默遗漏通用规则；可使用局部请求校验，不为此改变全局未知字段策略，也不建设旧策略解析兼容层。

规则及版本字段纳入请求幂等内容：相同请求重放复用，修改版本不得当作原请求。核对创建时冻结与持久化事务，避免部分写入。

## 2. 快照、执行和复制

新配置快照保存实际模型配置及修订、提示词 ID／名称、版本 ID／号、正文与适用用途；不再保存新策略关联。为新快照设置明确版本标识，区分可复制的新任务，不建设旧快照批量迁移。执行只读取冻结配置，不查当前策略或最新提示词。

`TaskDtos.ConfigView` 和复制 DTO 去除新流程策略字段，补齐直接提示词选择及必要预览信息。`TaskService.copyInput` 只保证新快照，回填实际模型和版本选择；提交新任务仍重新校验配置和源码范围。旧快照不支持复制时使用现有错误体系返回明确原因。新任务所引用配置失效时由用户重选，不静默换最新版本。

`PromptInput` 中策略命名改为通用规则语义，`PromptAssemblyService` 的段落名同步调整；专项 worker 与拆分路径逐项核对，确保逐文件说明及版本正文进入所有适用调用。保留统一组装入口，不新增泛化提示词引擎，不改变输出协议、预算、材料归属和重试规则。

## 3. 策略退出及数据库边界

核对并退出 `StrategyV2Controller`、`AgentStrategyService` 及仅供策略使用的 DTO／实体／Mapper；若移除实体前尚有编译引用，一并在本项清理。不得顺带改变旧路线未启用模块或项目、模型、提示词管理。

历史 V1–V7 等迁移不改写、不删减，以免已有数据库校验和失配。允许空库先运行历史建表迁移而最终不使用策略表；表存在不等于保留策略产品功能。如需增加快照字段或用途约束，按仓库现状追加迁移。删除策略表不是本项完成条件，实际删除需另定清单。

本机旧试运行库不承诺升级后所有任务可继续运行；切换前盘点在途任务并由负责人决定等待、取消或清理，不能一边运行旧 worker 一边重建数据。新结构验证使用独立测试环境，不自动清理当前库。内网正式起点必须验证空库完整初始化及必要配置建立。

## 4. 报告后续项 UPI-06

获准实施后核对 `PromptDtos`、`AgentPromptService`、数据库用途约束及前端枚举，增加 REPORT 用途支持（若已有则复用），保留 SPECIALIST／AGENT 隔离。

`ReportDtos.GenerateRequest` 增加可选规则及具体版本；`ReportGenerationService` 在接受生成请求时校验并冻结正文及版本。`ReportInputService` 继续负责来源材料冻结，不把规则正文混入来源事实。`ReportExecutionWorker` 只消费冻结配置；报告详情暴露本次规则摘要与冻结预览。核对现有快照存储位置，优先复用，不预设必须新增表。

`PromptAssemblyService` 的报告分支加入规则段及优先级声明，不能复用专项文件说明伪装报告要求。规则纳入完整输入容量计量及实际调用记录；超限按现有机制报错，不能偷偷截掉规则。报告来源引用验证及材料不足语义保持原行为。

## 5. 验证和交付

服务级覆盖直接配置、版本配对／用途／归属、无规则、错误模型、冻结后修改、幂等、新任务复制和旧请求拒绝；组装级覆盖三种专项及拆分说明归属。报告后续项增加冻结和事实／指令隔离回归。执行受影响测试及编译，再按变更范围补集成检查；真实网关探针默认关闭，实际调用另按负责人授权执行。

提交成果记录必须区分单元／集成检查、全新数据库初始化、真实模型和 PC 视觉。报告部署前迁移顺序及未验证项，不以现有库启动成功替代空库验证。
