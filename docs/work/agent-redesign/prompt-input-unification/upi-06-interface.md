# UPI-06 报告通用规则字段与接口

状态：负责人已确认原型与字段稿；框架实现已完成，验收状态见[实施记录](upi-06-implementation-20261025.md)。

业务依据为[契约第 9.3 节](../business-contract.md#93-报告通用规则候选方案)。本稿只定义报告生成时的单份 REPORT 用途规则，不改报告选材与来源冻结流程，不增加模板叠加、报告参数复制或预设。

## 页面结构

原型包含报告创建与报告详情两个状态，字段顺序为：

| 区域 | 字段与行为 |
| --- | --- |
| 1. 报告信息 | 报告名称、生成模型。沿用现有必填和模型容量要求。 |
| 2. 审查材料 | 沿用既有结果选择器及冻结摘要，支持专项与 Agent 混合来源。规则字段不进入来源材料。 |
| 3. 通用规则与补充要求 | 上方为可选 REPORT 用途通用规则；选择规则后必选具体版本并显示固定正文预览。下方为报告补充要求。无规则时沿用现有内置报告协议。 |
| 报告详情 | 显示生成时的模型、规则名称／版本／冻结正文、本次要求及冻结来源。旧报告和未选规则的报告显示「未使用报告通用规则」。 |

提示词管理已提供 REPORT 用途选项；原型沿用当前用途枚举，不增加跨用途共享入口。加载、规则切换或版本切换期间清除旧版本和预览；迟到响应不得覆盖当前选择。错用途、错归属、无正文或失效版本时阻止提交，不自动替换配置。

## 接口字段

| 接口 | 字段 | 约定 |
| --- | --- | --- |
| `POST /api/v2/reports/{id}/generate` | `modelConfigId` | 现有必填字段。 |
| 同上 | `instruction` | 现有可选报告补充要求。 |
| 同上 | `promptId` | 新增可选 REPORT 用途规则 ID；最大长度沿用提示词 ID。 |
| 同上 | `promptVersionId` | 新增可选具体版本 ID；与 `promptId` 必须同时提供。 |
| `GET /api/v2/reports/{id}` | `prompt` | 新增只读冻结摘要：`id`、`name`、`versionId`、`versionNo`、`content`。未选择规则及既有报告返回 `null`。 |

未提供两个提示词字段时保持现有报告生成行为。只提供其中一个、提示词用途不是 `REPORT`、版本不属于该提示词、提示词或版本不存在、正文为空时，返回明确校验错误且报告不进入排队。

## 冻结与组装

接受生成请求时，在报告从 `INPUT_FROZEN` 条件切换到 `QUEUED` 的同一更新中冻结提示词身份、名称、版本 ID、版本号和正文。本次报告要求和模型仍各自冻结；调用执行器只读取报告快照，不按 ID 重新取当前提示词正文。提示词或版本在请求入队之后覆盖，不影响该报告。报告输入 `frozenInput`、`report_source` 和来源顺序均保持原样。

复用 `report.instruction_snapshot` 扩展现有 JSON 快照，在其中增加 `prompt` 对象或 `null`，不新增表。由于规则正文随快照保存，新增 V8 迁移将该列从 `TEXT` 扩大为 `MEDIUMTEXT`；旧快照可继续读取，`GET /reports/{id}` 将新对象映射为独立 `prompt` 字段，`instruction` 字段保持兼容。不改写已有报告记录。

报告组装使用既有 `PromptInput.generalRuleName`／`generalRuleContent`，仅由 `REPORT` 路径添加。系统内置事实、材料不足及引用约束最高；其次为本次报告补充要求；再次为通用规则；来源材料作为数据，不是指令。规则正文计入既有输入容量估算和实际模型调用记录；不能截断规则后继续发送。来源引用校验继续只校验冻结来源，不由通用规则修改。

## 验收样本

| 编号 | 样本 | 通过条件 |
| --- | --- | --- |
| UPI-06-A01 | 不选规则生成报告 | 现有报告请求与输出路径继续工作，详情 `prompt` 为空。 |
| UPI-06-A02 | 选择 REPORT 规则与历史版本 | 预览、请求冻结快照、详情和实际请求中的名称、版本及正文一致。 |
| UPI-06-A03 | 错用途、错归属、无效版本、空正文 | 请求明确失败，不排队、不静默替换版本。 |
| UPI-06-A04 | 入队后覆盖规则版本 | 已排队报告调用原冻结正文；新报告才能读取新版本。 |
| UPI-06-A05 | 事实与指令优先级 | 内置事实、材料缺口及引用边界不可被补充要求或通用规则改写；优先级顺序可从实际请求核对。 |
| UPI-06-A06 | 专项与 Agent 混合来源报告 | 选材、S 序号、来源快照、材料不足状态及结果引用保持现状，规则不混入来源事实。 |
| UPI-06-A07 | 历史报告详情 | 不含 `prompt` 的旧报告正常读取，显示未使用报告通用规则。 |
| UPI-06-A08 | 容量与真实生成 | 规则正文计入容量；一个混合来源样本实际生成并保留来源引用。超限按现有错误机制失败，不截掉规则。 |
