## 原因与实施修改

原品牌区来自 [BasicLayout.vue](../../../../frontend/src/layouts/BasicLayout.vue)。侧栏收起至 `64px` 后，`.sider-inner` 仍保留左右各 `16px` 内边距，`.logo` 仍保留左右各 `8px` 外边距；扣除边框后，品牌区只剩约 `15px` 可用宽度。`34px` 的 `.logo-badge` 因而被 `.logo` 的 `overflow: hidden` 裁切。

原 `.logo-mark` 同时使用 `brightness(0) invert(1)`。原 favicon 自带不透明底色，该滤镜会把底色和图案都转为白色，内部细节无法正常显示。

已按确认的原型完成：

1. 左上角导入独立 SVG 标志，按 `34 × 34px` 显示，移除原来的颜色滤镜、重复底色和外层徽标容器。
2. 收起时去掉品牌区所受的横向内外留白，让图标在侧栏内居中；品牌区及图标不参与压缩，文字单独处理溢出，保留侧栏对整体内容的裁切约束。
3. 展开时显示系统名称，收起时不渲染名称；手动折叠与 Sider 的响应式折叠使用同一状态。
4. 只核对品牌区相关展示，不顺带调整菜单、业务接口或服务。
