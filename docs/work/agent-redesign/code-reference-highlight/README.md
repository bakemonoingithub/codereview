## 要解决的问题

一个问题对同一文件存在多段引用（截图中的 8 处位置 + 1 处辅助证据）。当前点击任一蓝色链接只打开材料弹窗，没有定位、没有高亮，也无法在引用之间切换。

本次草稿验证以下 5 点：

1. 点击问题下任意蓝色链接打开代码。
2. 弹窗左上角行号从被点击的范围开始（不是从 1 开始）。
3. 自动跳转并高亮目标范围。
4. 当前问题对该文件的所有引用同时高亮（含辅助证据）；同一审查其他问题对该文件的引用不标记。
5. 提供「上一处 / 下一处」并显示当前位置。

## 设计简报

沿用 [docs/design.md](../../../design.md) 的简报，本次不新增品牌基准：

- 用户：内网开发者在问题审查结果中核对代码依据，需要快速确认「问题引用的究竟是哪几段代码」。
- 调性：清晰、克制、可核对；代码是主体，控件不抢注意力。
- 参考：现有审查详情、材料阅读弹窗与 Ant Design Vue 组件；沿用项目 token（`--blue #2563eb`、`--line #e8edf3`、`--radius-modal 24px`、`--font-mono`）。

## 交互建议（草稿已实现）

### 打开与定位

- 点击任一「位置」或「辅助证据」链接，弹窗以**文件**为单位打开：同一路径、同一版本侧、同一 SHA 的引用归为一组，不按材料片段拆开。
- 默认显示「固定版本全文」（负责人确认），因为同一问题的多段引用可能落在不同拆分单元里；「保存片段」仍保留，用来区分「实际发送」与「扩展阅读」。
- 打开后直接把目标范围的第一行滚到代码区顶部，因此左上角行号就是链接上的起始行。
- 标题旁显示 `定位 第 97 行`（多行显示 `第 310–313 行`），随切换更新；路径、固定版本、侧、本次发送范围都在弹窗头部可见。
- 不在弹窗内切换文件；同一问题跨文件时关闭弹窗后点另一个链接（负责人确认）。

### 高亮

- 当前问题在此文件的所有位置与辅助证据范围都加浅蓝底色与左侧竖条；当前范围底色更深，起始行行号使用实心蓝色胶囊。
- 其他问题的引用保持普通代码样式，不加任何标记；弹窗底部写明「同一审查的其他问题引用不标记」。
- 范围包含首尾行；相邻但不重叠的范围分别高亮。完全重复的范围在导航中只保留一次。
- 演示样本：位置 8 处（97、150–151、187、191、229、249–250、288、410）加辅助证据 1 处（310–313），共 9 处引用、覆盖 14 行；弹窗计数含证据。

### 切换

- 顶部「上一处 / 下一处」与计数 `3 / 9` 始终可见；到首尾时按钮禁用，不循环（见确认第 4 项）。
- 不再增加引用条（chips）；「共几处、当前第几处」只由计数与「定位 第 … 行」表达，避免第二套导航（负责人确认）。
- 快捷键 `Alt + ←/→` 切换（底部有提示），不与代码横向滚动冲突。
- 短距离切换平滑滚动，长距离直接跳转；跳转后当前起始行有短暂闪烁，避免视线丢失。

### 模式与边界

- 工具栏在模式旁直接标出范围：保存片段为「实际发送 · 第 88–430 行」，固定版本全文为「全文件 1–860 行 · 扩展阅读，不改变发送内容」；头部同时保留本次实际发送范围。
- 「保存片段」下，不在发送片段内的引用不再有引用条可看；页脚会提示「N 处引用不在发送片段内」，切换到该引用时自动切回全文并提示；当前引用在片段内时直接定位。
- 「固定版本全文」读取中显示骨架；读取失败显示原因、重试与「返回保存片段」，引用与计数保留，重试成功后回到原引用。
- 单引用问题：计数 `1 / 1`，两个按钮都禁用；空文件与越界引用有兜底说明，材料缺失沿用现有页面的提示。
- 从「材料与边界」进入时不带问题上下文：标题标为「材料阅读」，上一个/下一个隐藏，不标记任何引用，用来对照「引用高亮属于问题，不属于文件」。

## 用户流程

| 场景 | 正常路径 | 空 / 加载 | 错误与恢复 |
|---|---|---|---|
| 从问题定位 | 点位置或辅助证据 → 全文中打开 → 目标行到顶 → 全部范围高亮 → 计数 1/9 | 全文加载显示骨架；材料缺失显示空态 | 读取失败保留引用与计数，可重试或回保存片段 |
| 浏览多处引用 | 上一处/下一处 → 滚动、更新计数与当前行 → 当前范围加深 | 单引用时按钮禁用、计数 1/1 | 越界/不在片段内时说明并给出切换全文的出口 |
| 核对发送内容 | 切到保存片段 → 只显示第 88–430 行，行号仍为原始行号 | 片段为空或缺失时提示 | 读取失败可回全文；切回不丢当前引用 |
| 区分其他问题 | 关闭后打开另一问题 → 只有该问题的范围高亮 | 其他问题在此文件无引用时只显示计数 | 不影响当前问题的计数与位置 |

## 与现有实现的差异

- [SpecialistResultView.vue](../../../../frontend/src/components/SpecialistResultView.vue) 现在只把单个 location 传给 `open-code`，不知道同一问题还有哪些引用，也没有合并 `evidence`。实施时需要把 `locations + evidence` 作为一组传出，或由详情页按 issue 聚合；辅助证据的显示入口仍保持现有独立行。
- [MaterialReaderModal.vue](../../../../frontend/src/components/MaterialReaderModal.vue) 现在按 `materialId` 打开，只读一个材料片段。从问题引用进入时应改为按 `path + side + sha` 读取固定版本全文，同时保留材料片段模式。
- [CodeViewer.vue](../../../../frontend/src/components/CodeViewer.vue) 用 `v-html` 渲染整段高亮，无法按行加成行状态。需要改为逐行渲染（或按行切分 highlight.js 输出），并支持 offset 行号、范围 class、滚动定位。
- 引用分组键建议为 `path + side + sha`；同一文件的前后侧行号不能混在同一个视图里。
- 加载全文需要新请求；打开时要保证「旧请求不覆盖新引用」，沿用现有 epoch/generation 防迟到响应的做法。
- 现有材料弹窗宽度为 `min(1000px, ...)`，本草稿采用 `min(1160px, ...)`（负责人确认），因为要容纳长路径、模式说明与导航。
- 不新增列表标记：弹窗打开期间也不给被点击的位置链接加蓝色底（负责人确认，已移除草稿中的该状态）。

## 已确认（2026-10-22）

| 项 | 结论 | 草稿处理 |
|---|---|---|
| 1. 默认视图 | 先看固定版本全文 | 已作为打开默认；保存片段仍可切 |
| 2. 辅助证据 | 纳入高亮、计数、上一处/下一处 | 位置 + 证据合并为 9 处；页面上证据仍单独一行 |
| 3. 引用条 chips | 不要 | 已移除，只保留上一处/下一处与计数 |
| 4. 到首尾 | 随引用条取消不再单独讨论 | 保留到端点禁用，不循环；如需循环再改 |
| 5. 跨文件 | 关闭后点另一个链接 | 弹窗内不切文件 |
| 6. 上次查看标记 | 不用 | 已移除打开期间的链接底色 |
| 7. 其他问题引用 | 不标记 | 保持普通代码样式 |
| 8. 弹窗宽度 | 1160 | 采用 `min(1160px, calc(100vw - 40px))` |
