## 2. 关键交互

- 保存一律带 `expectedRevision`；409 `REVISION_CONFLICT` 时保留表单并提示刷新，不自动覆盖。
- 凭据只显示"已配置／未配置"；编辑时输入框为空，留空即保留，输入新值才替换。
- 模型验证显示实际范围（可达与简单 JSON），不宣称完整窗口或工具协议；验证失败展示原因而非"验证完成"；配置修订后显示"配置已变更，验证过期"。
- 提示词编辑先加载详情；慢响应不覆盖用户已输入正文；正文有变化时先更新元数据再追加新版本，不覆盖历史版本。版本对比失败清空上一对结果并显示错误。
- 策略页先选专项类型；模型下拉为空或加载失败时给出"去创建模型"入口；未选模型不提交。
- 列表支持搜索与加载更多；空态、加载态、错误态分别实现，翻页失败不清空已加载项。

## 4. 人工视觉检查清单

对四个页面分别在 1366px 与 1920px、100% 缩放下检查：

1. 正常：列表、搜索、新建、编辑、删除／验证操作完整；长仓库地址与长标签不溢出。
2. 空状态：无数据时显示引导与新建入口；搜索无结果时提示调整关键词。
3. 加载状态：列表 loading；验证按钮请求期间禁用；保存按钮显示提交中。
4. 错误状态：列表加载失败可重试；保存失败保留表单；409 展示原因；验证失败展示实际错误。
5. 键盘与焦点：标签可点选、弹窗可 Esc 关闭、危险操作需二次确认。

## 5. 已知边界

- 项目 v2 没有删除接口，页面不提供删除入口，避免退回旧接口。
- 项目详情、代码浏览与任务发起仍按旧页面／后续任务接入；本次不把它们混入 v2 配置页。
- 提示词版本对比依赖已保存版本；不能把"覆盖当前版本"当作 v2 能力。
- Agent 用途提示词只做数据保留，P33 才接入选用与执行。
