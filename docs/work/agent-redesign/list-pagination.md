## 原型

[独立 HTML 原型](p29/prototype/pagination.html)提供 6 个页面切换与示例数据；[PC 预览](p29/prototype/pagination-preview.png)显示审查中心第 2 页。原型按现有页面的颜色、表格及侧栏结构演示分页，不替代各正式页面的字段和操作。

交互方案：

- 初次访问默认每页 20 条；底部显示总条数、当前记录范围、页码、上一页／下一页、每页条数选择和跳页。
- 切换每页条数或筛选条件后回到第 1 页；刷新保留当前页；查看详情后返回保留当前页。
- Cookie 名称以页面标识区分，保存期限为 1 年；不存在、不可读取或值不合法时使用 20 条。保存失败不阻断本次分页操作。
- 末页不足一页时只显示实际记录；没有匹配记录时显示空态，并禁止向前／向后翻页。

原型使用示例数据和本机静态 HTTP 预览；Cookie 在 HTTP 下验证，直接以文件方式打开时受浏览器本地文件 Cookie 限制。

## 正式实现

- 6 个列表接口支持 `pageNum` 和 `pageSize`，返回 `items`、`total`、实际 `pageNum`、`pageSize`。`AgentPaging.query` 在数据库计数和截取，计数复用列表筛选；排序保持 `created_at DESC, id DESC`。页码超过现有末页时回退到有效末页，0 条数据返回第 1 页。页码非正数、条数不在允许范围或混用 `cursor/limit` 时返回 HTTP 400。
- 未提供页码参数时继续使用游标查询，供其他下拉、选材和调用记录使用。`PageResponse.withItems` 在 DTO 转换时保留分页元数据。
- `useListPagination` 统一 6 页的条数偏好、请求顺序和失败重试。Cookie 为 `ai-review-page-size-<页面标识>`，标识分别为 `reviews`、`reports`、`projects`、`models`、`prompts`、`strategies`，设置 `Path=/`、`SameSite=Lax`。只保存条数；审查中心和报告的返回页码通过会话存储恢复，条数变化后不套用旧页码。
- 新建成功回到第 1 页；编辑、验证、删除和刷新重新请求当前页，删除后由后端校正末页。筛选或条数变化回到第 1 页。失败保留最近成功的数据和页码，重试失败的目标页；旧请求和卸载后的迟到响应不能覆盖当前页面。
- 分页使用现有 Ant Design Vue 表格控件，沿用中文语言包。只有一页时仍可选择条数；跳页输入由控件在存在多页时显示。
