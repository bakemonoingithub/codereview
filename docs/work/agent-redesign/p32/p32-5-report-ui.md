# P32.5 独立报告表单、多结果阅读及下载

状态：done（2026-10-21，PC 工程页面与本地真实数据自查）。负责人视觉确认归 [P32.6](p32-6-validation.md)，不以本记录的截图替代。

## 入口与页面

侧边栏新增「报告」，路由：

| 路由 | 页面 | 用途 |
| --- | --- | --- |
| `/reports` | `ReportList.vue` | 报告记录、状态、来源数量、类型分布、模型与时间 |
| `/reports/new` | `ReportCreate.vue` | 独立报告表单；先选材、填标题与模型，再冻结并生成 |
| `/reports/:id` | `ReportDetail.vue` | 状态轮询、正文、引用、来源、失败原因、实际调用与下载 |

`CallReaderModal` 支持无任务的报告调用读取；报告调用通过 `/api/v2/model-calls/{id}` 读取保存的完整请求与返回。

## 报告表单

- 报告名称（最多 200 字）、生成模型、补充要求（最多 4000 字）。
- 候选只来自完整发布结果；支持项目、类型筛选与游标分页。部分完成／取消任务中完整文件可选，未完成结果不出现。
- 跨页勾选保留；右侧显示已选来源与移除操作。提交前明确提示冻结来源、版本和当时反馈。
- 模型未声明上下文窗口时在选项中标注并禁用；默认优先选择可用模型，避免以不可用配置发起生成。
- 提交顺序：`POST /reports/inputs` 冻结 → `POST /reports/{id}/generate` 受理。冻结失败保留表单和选材；已冻结但生成受理失败进入报告详情，材料不丢。
- 未自动把任何失败文件或未完成片段包含进报告。

## 多结果阅读

- 页首显示结果数、来源任务数、仓库版本数、类型分布、冻结时间与模型。
- `QUEUED/RUNNING` 每 2 秒轮询；终态停止。读取失败保留已加载内容并提供重试。
- 成功报告正文与下载使用同一份保存 Markdown；正文中的 `[S1]` 渲染为可点击引用，打开对应冻结来源。
- 来源侧栏显示序号、类型、项目、路径、版本、问题数与反馈计数；来源抽屉展示结论、问题、模式／耦合事实、当时反馈、材料代码与缺失说明，不读取当前分支。
- 失败报告显示错误码与原因、保留来源，并展示实际调用；没有成功正文时下载被禁用，服务端返回 409。
- `INPUT_FROZEN` 报告可在详情页选择模型继续生成，不重新选材。

## 安全与展示

- Markdown 经 DOMPurify 净化；脚本和 `javascript:` 等危险协议不保留。代码块按文本转义，代码块内的 `[S]` 不替换为引用按钮。
- 报告时间按新库 UTC 存储换算为浏览器本地时间显示。
- 页面按 PC 场景设计，不新增手机适配任务。
