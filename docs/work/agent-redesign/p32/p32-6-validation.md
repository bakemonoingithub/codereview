## 真实报告生成

第一次生成（报告 `01M5F8M6PZEX9Y8ZEMB41DEESJ`）失败：`MODEL_OUTPUT_INVALID` /「模型输出因长度限制被截断」。原因是报告沿用了公共 4096 输出预留，而真实报告需要更长正文。模型调用与冻结来源均已保存，报告没有成功正文。

修复为报告用途显式输出预留 `agent.report.output-tokens=16384`，仍受模型最大输出限制，专项默认值不变。
