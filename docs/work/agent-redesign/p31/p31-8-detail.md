# P31.8 统一详情、材料阅读及实际调用查看

状态：完成工程实现与本地测试（2026-10-21，Asia/Taipei）。没有真实模型调用或 PC 视觉验收。

## 1. 交付

| 能力 | 位置 | 说明 |
| --- | --- | --- |
| 统一入口 | `TaskDetail.vue`、`/reviews/:id` | 任务头、目标列表、执行状态、取消与复制参数 |
| 三类结果 | `SpecialistResultView.vue` | 问题（位置/原因/建议/证据/变更关联）、模式候选、耦合解释与边界 |
| 结果读取 | `GET /review-tasks/{id}/targets/{targetId}/result` | 保存的结果正文、问题行、完整性、来源 |
| 材料列表 | `GET /review-tasks/{id}/targets/{targetId}/materials` | 实际关联材料、角色、发送状态、SHA、行号、完整性 |
| 材料原文 | `GET /review-tasks/{id}/materials/{materialId}` | 保存片段；扩展全文按固定 SHA 读取，不改变发送内容 |
| 材料阅读弹窗 | `MaterialReaderModal.vue` | 片段/全文/提交差异切换；声明摘要与拆片段明确不是完整源码 |
| 实际调用 | `GET /review-tasks/{id}/calls/{callId}`、`CallReaderModal.vue` | 按文件、片段、尝试查看完整请求、模型返回、错误和用量 |
| 反馈预留 | 结果页脚 | 只显示“P32 接入”，不保存评价 |

## 2. 行为边界

- 结果读取只返回已发布内容；片段部分失败时显示“文件未完成”，不能当完整文件结论或报告材料。
- 问题位置以服务端保存的路径、SHA、侧和原始行号为准；辅助证据单独列出，不当作问题目标。
- 材料只允许读取当前任务调用关联过的记录；跨任务材料返回 404。
- 调用记录必须属于当前任务；请求正文是当时实际发送内容，不回读模板重建。
- 详情页对执行中任务每 3 秒刷新；切换目标使用 epoch，迟到结果不能覆盖当前目标。
