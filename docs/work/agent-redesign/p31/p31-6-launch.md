# P31.6 发起表单、独立范围弹窗及参数复制

状态：完成工程实现与本地测试（2026-10-21，Asia/Taipei）；没有浏览器自动化截图，也没有真实仓库联调。

## 1. 交付

| 能力 | 位置 | 说明 |
| --- | --- | --- |
| 审查中心 | `ReviewCenter.vue`、`/reviews` | 任务列表、项目／类型／状态筛选、文件完成数、复制参数入口 |
| 发起表单 | `ReviewLaunch.vue`、`/reviews/new` | 项目、专项类型、文件内容／提交差异、分支固定版本、目标文件、策略或模型、逐文件说明、默认关闭的拆分开关 |
| 范围弹窗 | `ScopePickerModal.vue` | 独立文件树、搜索、展开／收起、全选筛选结果、清空；蓝色文件名只预览，复选框只选目标 |
| 代码预览 | 同一弹窗 | 文件原文行号；差异可切换改动／修改前／修改后；新增、删除、不可读分别提示 |
| 参数复制 | `ReviewLaunch.vue` | 从 `copy-input` 回填并重新读取分支 HEAD；版本移动时清空原范围并提示 |
| v2 读取 | `RepositoryV2Controller` | 分支 HEAD、提交列表、提交详情（去 patch）、路径、文件与差异 |
| 客户端 | `api/v2.ts` | `tasksApi`、`repositoryApi` 与任务/仓库类型 |

## 2. 交互边界

- 范围确认后才回填主表单；取消不改变原范围；移除已有说明的目标会随勾选移除对应说明。
- 分支版本在提交时由服务端再次核对；`SOURCE_MOVED` 不消费输入，页面提示并允许刷新版本与范围。
- 复制参数不继承旧材料正文或旧结果；FILES 重新观察 HEAD，DIFF 仍使用固定提交。
- 智能拆分默认关闭；表单说明“未开启时整文件提交、超限直接失败”。
- 选择策略时由策略带入模型，不再单独指定另一个模型。
