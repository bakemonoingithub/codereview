# P31.7 代码浏览与审查中心接入

状态：完成工程实现与本地测试（2026-10-21，Asia/Taipei）。没有连接真实 Git 宿主，也没有 PC 页面截图。

## 1. 交付

| 能力 | 位置 | 说明 |
| --- | --- | --- |
| 代码浏览 | `CodeBrowser.vue`、`/browser` | 项目、分支、文件/提交差异切换；固定版本读取；树搜索、勾选与预览 |
| 文件/差异预览 | 同一页面 | 文件原文带行号；提交差异复用 `DiffViewer`；不可审查文件不进入树 |
| 带入发起 | 同一页面 | 勾选文件写入 `review-launch-prefill`，打开发起页时带入项目、版本与目标 |
| 分支/提交读取 | `repositoryApi`、`RepositoryV2Controller` | 分支列表、HEAD、提交列表、提交详情、路径、文件、差异 |
| 审查中心 | `ReviewCenter.vue`、`/reviews` | 项目/类型/状态/任务 ID 搜索，游标分页，文件完成数，返回现场 |
| 任务详情入口 | `/reviews/:id`、`TaskDetail.vue` | 任务头、目标列表、结果/材料/调用页签；本项先接通入口与状态明细 |

## 2. 交互边界

- 列表筛选写入 `sessionStorage`，从详情返回时恢复；筛选请求带 epoch，迟到响应不能覆盖新条件。
- 代码浏览的来源变化（项目/分支/模式/提交）会递增 epoch 并清空选择与预览；目标文件列表只含可审查文件。
- 审查中心顶部不恢复文件完成情况和问题准确率卡片；文件计数在任务行，详情内显示任务级完成情况。
- 代码浏览只有文件级勾选，不提供方法或行范围目标；提交差异仍在问题审查范围内。
