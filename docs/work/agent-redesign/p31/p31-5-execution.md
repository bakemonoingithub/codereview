# P31.5 逐文件执行、批量状态与结果发布

状态：完成（2026-10-21，Asia/Taipei）。范围为本地执行器、发布器与固定样本单测；没有连接真实数据库或模型网关。

## 1. 交付

| 能力 | 位置 | 说明 |
| --- | --- | --- |
| 任务执行器 | `SpecialistTaskWorker` | 接入 `TaskWorker`，逐目标准备、增强、规划、调用和发布；一个文件失败不丢弃其他文件 |
| 批次状态 | 同一执行器 | 全部目标成功→`SUCCEEDED`；有可用结果→`PARTIAL`；全部失败→`FAILED`；取消/期限继续向上抛出 |
| 单元执行 | 同一执行器 | 每次真实调用经 `ModelInvocationService`；文件与片段共用公共并发许可 |
| 格式重试 | 同一执行器 | 初次 + 最多 2 次；只对可观察协议错误重试，诊断带回实际错误码与有界返回片段 |
| 不可变发布 | `SpecialistResultPublisher` | 合并片段后写 `review_result` 与 `issue`；完整结果 `COMPLETE`，部分成功 `INCOMPLETE` |
| 来源记录 | 同一发布器 / 执行器 | 保存版本、材料、单元范围与调用；每次成功或失败尝试关联实际发送材料 |
| 稳定 ID | 同一发布器 | 问题 ID 在发布时生成；结果正文不可变 |

## 2. 行为边界

- 完整文件只有全部单元成功才发布 `COMPLETE`；部分片段失败保留已取得内容并发布 `INCOMPLETE`，不进入正式选材。
- 目标读取、材料准备或规划失败只标记该目标失败；其他目标继续，任务最终可为 `PARTIAL`。
- 取消或期限在准备前、每次调用前后及发布事务内检查；取消后已完成结果保留，未完成目标停止。
- 发布器不生成跨文件联合结论；`source_units` 记录参与该结果的单元，正文仍是各片段结果的程序归并。
- `EXECUTOR_UNAVAILABLE` 不再是当前运行的预期行为：已注册专项执行器。
