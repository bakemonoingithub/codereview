## 3. 已覆盖的语义

- 同名条目仍有不同 ID；重复建索引不更换 ID，已有序号缺口可补齐；错类型、重复序号、越界和损坏正文拒绝处理。
- 空库扫描为零；失败阻止数据库 Bean 发布并释放连接池；受控中断后重试保留此前已处理结果的 ID。此处为替身检查，未连接真实库。
- 模式两条反馈分别保存准确／不准确；伪造 ID、错类型、未完成和缺失索引拒绝；仅评论及 revision 冲突沿用统一保护。
- 条目统计包含尚无反馈的主体，与历史 RESULT 分开；问题、模式和耦合不混算，空分母为空值。
- 第 2 版冻结逐条反馈及关联；修改当前反馈后快照保持原值；旧快照按原整份结果反馈读取。损坏的第 2 版条目身份不能构造完整报告事实。
- 新 tab 使用 ordinal 关联服务端 ID；空结果和未完成不出现反馈入口。缺失材料禁用代码链接；跨文件、修改前后版本及原始行号仍通过公共代码引用工具阅读。
- 新 tab 的反馈允许保存在途时继续编辑，成功响应只更新已保存基线，后续输入继续显示未保存。清除评价保留评论，评论直接展示，HTML 内容按文本转义。
