# 报告来源阅读视图

日期：2026-10-27。状态：负责人已验证并确认原型，正式前端改造及定向工程检查完成；正式页面视觉待确认。业务边界见[契约第 6.4.4 节](../business-contract.md#644-报告来源只读视图2026-10-27)。

## 1. 已确认方向

负责人同意复用 Agent 分析与专项审查结果组件，接受为报告冻结来源维护独立的只读视图，并要求头部信息归类参照当前详情页，将输入与配置类信息收拢到相应 tab。

负责人在验证[独立原型](prototype.html)后明确要求修改正式页面。本轮据此实施前端改造；原型使用演示数据，不连接业务接口，原型确认与正式页面验收分别记录。

## 2. 已确认的布局

| 区域 | 展示内容 |
| --- | --- |
| 头部 | 来源编号、报告快照与只读标识，项目、审查类型、专项文件名；一行说明结果、反馈和材料取自报告生成时的保存内容 |
| 审查结果 | Agent 正文、材料不足及未解决事项、代码证据；专项总结、逐条结论、依赖事实、材料边界；对应结论下方展示当时评价与评论 |
| 输入与配置 | 来源范围（项目、类型、已记录分支及源码版本、专项目标文件）、代码材料、冻结记录（来源编号、任务 ID、结果 ID、结果发布时间、冻结时间） |
| 底部 | 打开原审查详情、关闭；原详情用于查看完整任务配置、实际调用及当前反馈 |

原型合并原有「冻结材料」tab 到「输入与配置」，将「当时反馈」放到对应结论下方。第 1 版模式／耦合以及 Agent 的历史结果级反馈使用独立只读区，不将整份评价分摊到条目。逐条反馈以冻结的 ordinal 和稳定标识关联正文，不依赖数组的偶然顺序。

头部不再平铺任务 ID、结果 ID、分支、完整 SHA 或冻结时间。正文保留材料不足和缺失边界，不因归类而隐藏影响结论理解的信息。原型覆盖 Agent、问题、模式、耦合、历史整份评价和信息缺失六种示例；页签、代码阅读示意、关闭与重新打开可交互。

## 3. 已核对的数据边界

`ReportInputService.snapshot` 当前保存项目、任务路线／类型／状态、来源分支与提交、专项目标路径及前后版本、结果正文与 provenance、代码材料正文、问题及反馈、条目及反馈、历史整份反馈、结果发布时间与冻结时间。

当前快照未保存完整任务名称、全部目标选择、Agent 多提交配置、本次要求、模型配置、通用规则正文及任务创建／结束时间。不能为追求与原详情字段完全相同而调用当前任务接口补齐，再将其作为报告当时的冻结依据。输入 tab 使用已冻结字段，给出一次简短的配置范围说明；完整配置经原审查详情入口读取。

材料的 `role`、`sent` 与调用关联在当前材料快照中不完整，不能从字段缺失推断「未提供给模型」或虚构用途分组。`COMPLETE` 仅表示所保存范围的完整程度，不直接解释为整份文件。Agent 多版本应保留引用材料各自的 SHA 与版本侧，不能由一个顶层提交替换所有材料版本。

本轮不扩展冻结接口或迁移数据库。若后续需要在来源视图内展示完整任务配置，应另行明确冻结字段和版本规则，历史快照仍显示实际已保存的信息。

## 4. 实现划分

- `ReportSourceModal` 保留来源读取、加载失败重试、来源切换和迟到响应保护；头部、tab 与滚动区域承担报告只读视图的组织职责。
- Agent 正文继续复用 `AgentResultPanel`。专项复用 `SpecialistReviewResultTab` 的结论展示与样式，新增反馈插槽和 `readOnly` 参数；报告视图通过 `FrozenFeedbackView` 展示快照内的评价和评论，默认编辑行为保持不变，只读模式不挂载反馈编辑器，也不提示保存或修复可编辑标识。
- 代码阅读继续复用 `CodeReferenceModal`。冻结片段取报告快照；固定版本全文属于额外上下文，保留明确区分；快照缺失不回查当前任务材料。
- 原审查详情保留既有布局、编辑反馈与调用查看行为；报告创建预览等其他调用方保持当前默认行为。原详情另开页面并定位专项目标，不丢失报告的阅读位置。

## 5. 实现后的验证范围

1. 四类结果均正确展示；条目反馈、无反馈仅评论、历史整份反馈及未记录信息保持原含义。
2. 来源读取与只读反馈不请求当前反馈接口；当前反馈更新不改变旧报告展示。
3. 代码引用保持材料 ID、SHA、版本侧、原始行号；缺失正文有提示，固定版本全文与冻结片段可区分。
4. 切换来源、关闭及重试后不接受过期响应，嵌套代码阅读关闭不影响外层来源。
5. 头部不平铺输入／记录信息；长路径和窄窗口可阅读；正式 PC 页面视觉由负责人确认。

原型检查不替代正式接口、真实数据库、模型调用或正式页面视觉验收；不启动 SRF-07，不改变现有工作包状态。
